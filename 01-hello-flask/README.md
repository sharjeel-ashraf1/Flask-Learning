# Day 01 – Getting Started with Flask

## Overview

Created my first Flask application and learned how to set up and run a basic web application using Python's Flask framework.

## Concepts Learned

- Introduction to Flask
- Importing Flask
- Creating a Flask application instance
- Understanding `app.run()`
- Running a local development server

## Implementation

Created a basic Flask application using the `Flask` class.

The application instance acts as the central object through which we configure routes and handle incoming HTTP requests.

## Code Structure

- `app.py` – Contains the Flask application code.

## How to Run

```bash
python app.py
```

The application runs on Flask's local development server, allowing it to be accessed through a web browser.

## Key Takeaway

Learned how to create and run my first web application using Flask.
